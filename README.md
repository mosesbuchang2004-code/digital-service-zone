# Hotsub: Your Digital Hub

Build a modern, premium Virtual Top-Up (VTU) web application called HOTSUB. The platform should allow users to purchase airtime, data bundles, cable TV subscriptions, electricity tokens, exam PINs, and other digital services seamlessly.

The design should match the provided HOTSUB logo and brand identity.
